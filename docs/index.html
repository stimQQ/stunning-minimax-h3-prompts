Stunning MiniMax H3 Prompts

An open collection of prompts for MiniMax H3 (Hailuo 3.0), the video model ByteDance released on 31 July 2026.

Video prompting is mostly folklore. Almost every prompt you find online is text with nothing attached — no clip, no credit, no way to tell whether it produced anything worth having. This library exists because that gap is fixable: every prompt here is stored next to the video it actually generated, and credited to whoever wrote it.

The collection is maintained as a dataset in this repository and published as a browsable gallery, where each clip plays with its native audio.

How it is put together

  • Author-written prompts are indexed with credit and a link to the original post. We do not own them, so we point at them rather than relicensing them.
  • Reconstructed prompts cover clips whose author never published one. Eight frames are sampled and handed to a vision model, and the result is labelled as reconstructed — it describes the output, so it cannot recover negative constraints or reference-image workflows. Those are MIT licensed and included in full.
  • Prompts stay in the language their author wrote them in. A translated prompt does not generate the same clip.

Contributing

Seen a good H3 clip? Open an issue with the link. If the creator published the prompt it gets indexed with credit; if not, it can be reconstructed and labelled as such. Creators who want an entry removed can open an issue too.
